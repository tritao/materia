# About Materia

Materia is a 0.x open-source project: one stack, written mostly in Haxe, to
design, simulate, plan and run machines. These pages describe it as it is in
the repository today. For how the pieces fit together, read
[Materia in one page](../concepts/start/overview.md).

- [Features](features.md): what Materia can do today, stage by stage, with a
  link to the concept page behind each feature, and a short list of what is
  planned.
- [Gallery](gallery.md): every example machine, what it shows, which concepts
  it exercises, and the command that opens it in the editor.
- [Licensing](licensing.md): what is open and under which licence, the
  third-party components and their licences, and what will be commercial
  later.
