# Materia documentation

Materia is an open stack for building machines in software: model the parts and
the mechanism, derive the motion limits from the real motors and transmissions,
plan and simulate the work, and run it on hardware through an open controller
protocol.

- **New here?** Read [The life of a machine](concepts/start/life-of-a-machine.md):
  one gantry followed from geometry to the controller.
- **Want the ideas?** The [concepts](concepts/README.md) explain each layer and
  where its boundaries are.
- **The project:** what is open and what is commercial is in
  [Open core](OPEN_CORE.md); how these docs are built is in the
  [documentation plan](DOCS_PLAN.md).
