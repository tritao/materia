# Commands and shortcuts

Every action in the editor is a **command** with a stable ID. Toolbar buttons,
menus, the command palette and keyboard shortcuts run the same commands, so a
command greyed out in one place is greyed out everywhere.

- **Command palette**: Ctrl+K or Ctrl+P. Type part of a label or an ID, move
  with Up and Down, and press Enter. It lists every command below; the ones
  that do not apply right now are greyed.
- **Shortcuts** are the defaults. Change them under **Editor Settings >
  Shortcuts** (see [Settings](settings.md#shortcuts)).
- Ctrl is the Control key on every platform.

This page is generated by hand from the registrations listed under each
table; those are the places a generator should read. A command's ID, label and
default shortcut are the arguments of `new Command(...)` in that file.

## Keys that are not commands

These are handled by the widget under the focus or the pointer, so they cannot
be rebound.

| Where | Key or gesture | Effect | Defined in |
|---|---|---|---|
| 3D view | Middle-drag, Alt+left-drag | Orbit | `app/src/EditorPerspectiveViewport.hx` (`installNavigation`) |
| 3D view | Shift+middle-drag, Shift+Alt+left-drag | Pan | same |
| 3D view | Wheel | Zoom towards the cursor | same |
| 3D view | Hold right button; W A S D, Q E, Shift | Fly; down and up; faster | same (`advanceNavigation`, `flyKey`) |
| 3D view | Escape | Stop flying; cancel a drag, sketch drag or mate pick | same |
| 3D view | Space | Show or hide the selection (not during simulation) | same (`visibilityKey`) |
| 3D view | Left click, left-drag | Select; move an object or joint | same |
| Hierarchy | Space | Show or hide the selected row | `app/src/editor/HierarchyTreeView.hx` |
| Hierarchy | F2 | Rename | `haxeon/packages/ui/haxe/haxeon/ui/widgets/collections/TreeView.hx` |
| Hierarchy | Up, Down, Home, End, Page Up, Page Down | Move the selection | same |
| Hierarchy | Left, Right | Collapse, expand | same |
| Hierarchy | Menu, Shift+F10, right-click | Row menu | same |
| Hierarchy | Double-click | Frame the row | `app/src/editor/HierarchyPanel.hx` |
| Command palette | Up, Down | Move between enabled commands | `haxeon/packages/ui/haxe/haxeon/ui/widgets/commands/CommandPalette.hx` |
| Console | Ctrl+C | Copy the selected text | the Console's text area |
| Machine panel | Shift while dragging | One-tenth sensitivity | `app/src/editor/MachineControlPanel.hx` |
| Shortcuts tab | Escape while recording | Cancel recording | `haxeon/packages/ui/haxe/haxeon/ui/widgets/settings/ShortcutsPanel.hx` |

## Open questions

- **Commands without a way in.** The viewport context menu
  (`app/src/Main.hx:883-904`) is never shown, so the mate commands are reachable
  only from the palette, and the menu's other entries only from their other
  places.
- **Two Play commands.** F5 is bound to `sim.toggle`, while the toolbar's Play
  and Pause buttons run `sim.play` and `sim.pause`, which have no shortcut
  (`app/src/editor/SimulationCommands.hx`). Rebinding "Simulation: Play" in the
  Shortcuts tab therefore does not change F5.
- **Delete has no key.** `scene.delete` is registered without a shortcut
  (`app/src/editor/SceneObjectCommands.hx`), so pressing Delete does not delete
  the selection unless you bind it under Shortcuts.
