# Casting shop declaration

`CastingShopRecipe` supplies fresh tooling, compaction, process, fabrication and
panel-CAM records to casting examples. Add this directory as a Haxeon source root;
it is example configuration, not a library default or a separate package.

Production compound, equipment and coupon evidence remain unresolved. Consumers
keep their existing readiness checks. Machine setups own geometry, orientations,
feature allocation priorities and source interface requirements.

Current mill exceptions are geometric: the column wire direction follows its
front-on-bed orientation, and its side-open service passages withdraw along mold Y.
The mill resolves service and clearance recess ownership before lightening voids.
Those choices remain in the mill setup with their reasons. The shared recipe does
not acquire a mill feature-ID table.
