# XYZ stage

A small table-top XYZ stage: three lead-screw axes (12 mm trapezoidal, 3 mm lead) on MGN12 profile rails, NEMA 17 steppers, an
aluminium-profile frame. Travel is 200 x 150 x 100 mm. It is a `machinekit.gantry.Gantry`, so its joints `x`, `y` and `z`, their limits
and drives are the real ones of a gantry, and the jog pendant can be bound to them.

Open `materia.project.json` from Materia's Start page. The layout is not tuned for any process.
